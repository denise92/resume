# feat(resume): 列印 / 存成 PDF，並整理標籤與舊圖檔

## Why

- 很多投遞管道只收 PDF，需要讓網站可以直接「列印 → 另存為 PDF」。
- 作者確認：NoSQL 改為 MongoDB、拿掉「後台 UX 流程優化」標籤、廣告描述改用企業帳號授權的寫法。
- 圖片已經改用 webp，舊的 png / jpg 已經用不到。

## What

### 列印樣式（`src/style.css` `@media print`）

- A4 白底黑字，移除陰影、模糊、漸層
- 用 `data-print` 標記控制列印行為：
  - `hide`：列印時隱藏。用於導覽列、回到頂端按鈕、頁尾、Hero 背景圖、經歷縮圖、系統截圖、聯絡按鈕
  - `expand`：列印時強制展開。用於「主要負責的系統」三段原本收合的說明
  - `only`：只在列印時顯示。用於聯絡資訊（Email、LINE、GitHub、線上版網址）
- 縮小字級與留白，技術棧在列印時排成 3 欄，PDF 共 5 頁
- 經歷條目與聯絡區塊避免被分頁切開

### 列印按鈕

聯絡區新增「🖨️ 列印 / 存成 PDF」按鈕（`window.print()`），列印時會自動隱藏。

- 技術棧：NoSQL 改為 MongoDB
